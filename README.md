# W Coach

W Coach is a Codex skill for college writing feedback and guided revision. It checks assignment requirements, argument development, evidence, paragraph structure, ESL-aware language, and MLA citations while preserving the student's ideas and voice.

## Install

Clone the repository into your Codex skills directory:

```bash
git clone https://github.com/zby061204-ai/w-coach.git ~/.codex/skills/w-coach
```

Then invoke it with `$w-coach`, for example:

```text
Use $w-coach to review this draft against the attached assignment prompt.
```

The skill can optionally use project-local `VOICE.md`, `COURSE-RULES.md`, and `WRITING-MEMORY.md` files. These files are personal configuration and are not included in this repository.
